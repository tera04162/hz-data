코인 거래소 계정이 해킹당했다는 이야기를 들으면 "거래소가 뚫렸나 보다"라고 생각하기 쉽습니다. 하지만 개별 이용자의 피해는 거래소 서버가 아니라 이용자 본인의 계정이 털리는 경로에서 훨씬 자주 발생합니다. 같은 비밀번호를 여러 사이트에 쓰거나, 가짜 사이트에 로그인 정보를 넣거나, 문자 인증이 가로채이는 식입니다. 이 글은 거래소 계정을 지키는 설정을 우선순위 순서대로 정리했습니다. 거래소마다 메뉴 이름은 다르므로 앱에서 같은 기능을 찾아 적용하세요.

계정이 털리는 대표 경로

  • 재사용된 비밀번호. 다른 사이트에서 유출된 이메일·비밀번호 조합으로 거래소 로그인을 시도하는 공격이 흔합니다.
  • 피싱 사이트. 거래소와 똑같이 생긴 가짜 로그인 페이지에 정보를 입력하는 경우입니다. 검색 광고나 문자 링크로 유도됩니다.
  • 인증 수단 탈취. 문자 인증은 유심 복제(심 스와핑)나 악성 앱으로 가로채일 수 있습니다.
  • 악성코드와 원격 제어. 설치한 앱이나 "원격 지원" 요청을 수락한 뒤 화면을 통째로 조작당하기도 합니다.
  • 사칭 상담원. 거래소 직원을 사칭해 인증 번호나 OTP 코드를 알려 달라고 하는 전화나 메시지가 있습니다. 정상 직원은 비밀번호나 인증 코드를 요구하지 않습니다.

설정 순서

보안은 한 번에 모든 것을 완벽하게 하기 어렵습니다. 아래 순서대로 한 단계씩 해 두면 대부분의 위험을 줄일 수 있습니다.

1. 이메일 계정부터 지키기

거래소 비밀번호 재설정은 대부분 이메일로 이루어집니다. 이메일이 뚫리면 거래소를 아무리 잘 지켜도 소용이 없습니다. 이메일에 2단계 인증을 켜고, 이메일 비밀번호는 다른 곳과 겹치지 않게 합니다.

2. 거래소 전용 비밀번호 만들기

길고 무작위한 비밀번호를 비밀번호 관리자에 저장해서 씁니다. 생일이나 전화번호를 변형한 비밀번호는 피하세요.

3. 2단계 인증을 가장 강한 방식으로

SMS는 설정이 쉽지만 가장 약한 편에 속합니다. 가능하다면 인증 앱이나 보안키를 쓰세요. 앱 OTP를 쓸 때는 휴대폰을 바꾸거나 잃어버렸을 때 복구하는 방법(백업 코드, 이전 절차)을 미리 확인해 둡니다.

4. 출금 관련 보호 장치 켜기

거래소가 제공한다면 다음 기능을 켜 두세요.

  • 등록한 주소로만 출금하는 기능
  • 새 주소나 새 기기로 로그인한 뒤 일정 시간 출금을 제한하는 기능
  • 출금 시 별도 인증 요구

5. 로그인 알림과 기기 관리

새 기기 로그인, 비밀번호 변경, 출금 요청 알림을 켜고, 로그인된 기기 목록을 가끔 확인해 모르는 기기를 로그아웃합니다.

6. 피싱 방지 코드 설정

일부 거래소는 이메일에 사용자가 정한 코드를 함께 보여 주는 기능을 제공합니다. 이 코드가 없는 메일은 가짜 메일일 가능성이 높습니다.

7. 접속은 북마크나 공식 앱으로

검색 결과의 광고 링크나 메신저로 받은 링크 대신, 공식 앱이나 직접 저장한 북마크로 접속합니다. 주소창에서 철자를 한 글자씩 확인하는 습관도 도움이 됩니다.

8. 휴대폰 보안

운영체제와 앱을 최신으로 유지하고, 출처가 불분명한 앱 설치와 원격 제어 앱은 피합니다. 통신사의 유심 보호 서비스가 있다면 가입합니다.

9. 공용 와이파이와 공용 PC에서 로그인하지 않기

불가피하다면 로그인하지 않거나 사용 후 반드시 로그아웃합니다.

10. 큰 금액은 거래소에 오래 두지 않기

거래에 쓰지 않는 장기 보유 자산은 개인 지갑으로 옮기는 방법이 있지만, 그 과정에서 시드구문 관리 책임이 본인에게 넘어옵니다. 장단점은 <a href="/search?q=핫월렛">핫월렛과 콜드월렛</a> 글에서 다뤘습니다.

11. 이용 약관과 공지 확인

거래소가 안내하는 보안 정책, 점검 공지, 피해 발생 시 절차를 알아 두면 사고 때 빠르게 움직일 수 있습니다.

12. 비상 상황 대비

가족이 알아야 할 최소한의 정보(어느 거래소를 쓰는지, 복구 방법의 위치)를 안전한 방식으로 남겨 두면 본인이 어려운 상황이 되었을 때 도움이 됩니다. 비밀번호 자체를 공유하라는 뜻이 아니라, 복구 절차가 어디에 있는지를 알려 두라는 뜻입니다.
